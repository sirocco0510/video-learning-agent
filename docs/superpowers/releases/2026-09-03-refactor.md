# Refactor Consolidation — Release Notes (2026-09-03)

Consolidates 15 micro-refactor plans (`R.1` through `R.15`) executed under the
2026-09-03 refactor consolidation sequence. Net effect: less duplicated code,
fewer dead wrappers, cleaner module boundaries, no behavioral regressions.

This release ships **structural changes only**. There are no user-facing FR
changes; `requirements.md` and `implementation-plan.md` remain unchanged.

## Plan-premise corrections

Two items in the original R.11 task brief were corrected during execution:

- **Class name.** The brief referred to `BrowserRecordStrategy`. The actual
  class is `BrowserRecorder` (in `src/vla/subtitle/browser_record.py`). All
  audit greps and release-note references in this document use the correct
  name.
- **R.12 refiner migration: N/A.** R.12 was scoped to extract
  `subtitle/normalize.py` (FormatHint + Segment + per-format parsers), and the
  brief assumed a follow-up migration of `SubtitleRefiner` to consume
  `list[Segment]`. Per ruling during R.12 execution, the refiner's input
  contract is out of scope — `SubtitleRefiner` still operates on the legacy
  string path. The `normalize` module ships standalone and is consumed by the
  subtitle strategy / future readers only. This is **intentional**, not an
  oversight.

### Acceptance-code block status (informational)

The R.11 acceptance-code snippets in `implementation-plan.md` use the
pre-refactor public API. After the consolidation, several entrypoints moved
(`LLMClient.from_env` → `LLMClient(config, model)`,
`VideoSourceFactory.from_config` → `VideoSourceFactory(config)`,
`SubtitleStrategyRegistry.default` → `SubtitleStrategy(...)` constructor,
`WhisperRunner.from_config` → removed (logic moved into
`VideoLearningAgent._process_one`), `MacOSNotifier` lives in
`vla.ui.macos_notify`, `LLMSummarizer.from_config` → constructor injection,
`vla.main.run_session` → `VideoLearningAgent.run`,
`QuotaTracker.from_config` → `QuotaManager(config)`). These are refactor-driven
renames and do **not** indicate a regression; pytest covers the new shapes.

## Migration notes

No external migration needed. The only YAML-level change is R.10:

```yaml
# Legacy (still works):
  quality_check:
    model: gpt-4o-mini
    refine_model: gpt-4o-mini
  summary:
    model: gpt-4o-mini

# New canonical:
  llm:
    model: gpt-4o-mini
```

The legacy keys are auto-migrated on `VLAConfig.model_validate(...)`. No
user action required.
